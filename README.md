# tg_electro_notify

Telegram-бот с графиками отключений света **Полтаваобленерго** (poe.pl.ua).

- Очередь выбирается в меню бота (кнопки 1.1 … 6.2), её можно сменить в любой момент.
- Кнопки **📅 Сьогодні / 📆 Завтра**: интервалы без света и почасовая шкала 🟢🟡🔴.
- Каждые 10 минут бот проверяет сайт и пишет, когда появился или **изменился** график вашей очереди.
- Напоминает за 30 минут до начала отключения.
- Если сайт перестал отвечать, бот оставляет последний известный график и (если задан `ADMIN_CHAT_ID`) один раз сообщает об этом.

## ⚠️ Где запускать

Сайт poe.pl.ua **обрывает соединения с зарубежных IP**: из облака (США) соединение сбрасывается.
Поэтому GitHub Actions и зарубежные VPS, скорее всего, не подойдут. Запускайте бота **в Украине**:
на домашнем компьютере, Raspberry Pi, роутере с Docker или украинском VPS.

Бот работает через long polling, поэтому белый IP и домен не нужны.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. `cp .env.example .env` и впишите `BOT_TOKEN`.
3. Запустите один из вариантов:

**Docker (рекомендуется):**
```bash
docker compose up -d --build
docker compose logs -f
```

**Без Docker (Python 3.11+):**
```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

4. Откройте бота в Telegram → `/start` → выберите очередь.

## Как бот получает данные

`POST https://www.poe.pl.ua/customs/newgpv-info.php` с полем `seldate={"date_in":"ДД-ММ-ГГГГ"}`.
Это тот же запрос, который делает страница «Графіки погодинних відключень» на сайте.
В ответе HTML: блоки `div.gpvinfodetail` (сегодня/завтра) с таблицей `table.turnoff-scheduleui-table`,
где ячейки `light_1`/`light_2`/`light_3` означают «свет есть» / «отключено» / «возможно».

Формат восстановлен по открытым проектам и **ещё не проверен на живом ответе** (из облака сайт недоступен).
Тесты (`tests/`) гоняются на синтетическом HTML такой же структуры. Если после запуска бот пишет
«Графіка ще немає», а на сайте график есть, сохраните ответ сайта:

```bash
curl -s -X POST https://www.poe.pl.ua/customs/newgpv-info.php \
  --data-urlencode 'seldate={"date_in":"'"$(date +%d-%m-%Y)"'"}' > tests/fixtures/real.html
```

и пришлите его. По нему поправлю парсер.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

| Файл | Что делает |
|---|---|
| `bot/poe.py` | запрос к сайту и разбор HTML |
| `bot/storage.py` | SQLite: пользователи, графики, отправленные напоминания |
| `bot/texts.py` | форматирование сообщений |
| `bot/main.py` | меню, команды, фоновые проверки |
